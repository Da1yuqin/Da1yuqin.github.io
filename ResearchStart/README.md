# 科研入门 · ResearchStart

给科研新手的指南。第一章从选题与阅读论文开始，附 StarPaper、StrongResponse，以及评论和正文批注。

[阅读指南](https://da1yuqin.github.io/ResearchStart/)

页面沿用 [StarPaper](https://github.com/Da1yuqin/StarPaper) 的同一模板，完整复用其样式、搜索、主题切换、目录、复制、评论和批注脚本，代码遵循 MIT 许可，见 [LICENSE](LICENSE)。评论与批注使用独立讨论路径 `/ResearchStart/`。

纯静态页面，无需构建。在此目录运行 `python3 -m http.server 8000` 即可预览。正文在 `index.html`，资源在 `assets/`；均为相对路径，复制整个目录即可使用。
