# 科研入门 · ResearchStart

给科研新手的指南。第一章从选题与阅读论文开始，附 StarPaper、StrongResponse，以及共享评论和正文批注。

[阅读指南](https://da1yuqin.github.io/ResearchStart/)

纯静态页面，无需构建。在此目录运行 `python3 -m http.server 8000` 即可预览。正文在 `index.html`，样式和交互在 `assets/`。复制整个目录即可使用，资源均采用相对路径。评论和批注复用 StarPaper 的公开服务，独立讨论路径为 `/ResearchStart/`，写入来源沿用现有站点权限。

`assets/comments.js` 复用自 [StarPaper](https://github.com/Da1yuqin/StarPaper)，遵循其 MIT 代码许可，见 [LICENSE](LICENSE)。
