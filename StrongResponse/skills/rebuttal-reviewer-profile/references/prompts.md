# 审稿人画像与模拟 · 提示词

```text
读取 rebuttal-reviewer-profile/SKILL.md。完整 reviews：【】；评分与 Confidence：【】；论文：【】；二轮讨论：【】。先逐句提取 Weaknesses、Questions、Strengths、Summary 和评分理由，保留原话位置。建立每位审稿人的画像与投入表，逆推核心关切、情绪价值、实验量、背景解释与细节偏好；每项附原话依据，未知写未知。指出要求最高的问题、期待的回应和模拟严格程度。没有回复时先交付画像；已有 Rebuttal 时，再按画像逐题模拟审核，给出具体反馈，交给 Rebuttal skill 修改后重查。 已有回复时逐位提供完整原话、原评分与讨论，让 AI 扮演审稿人并判断模拟提分、维持或降分。提分时结束该分支，降分先给具体理由再交 Rebuttal 修改，维持时处理未解决关切；维持且已无可执行修改或原分已满分时，记录理由并交作者人工确认；按同一口径再审。材料不足写无法判断。最后交作者人工核对事实与幻觉，模拟改分不写入正式回复或 AC letter。
表达要求：用最简洁、最直白的话回答对方的具体问题，先给答案，再给必要证据和位置。不用空话、套话，不重复背景和结论，不作无关扩展。不添加任何防御性陈述。
实验数据优先用表格呈现，列出对照、关键条件、数值、单位及必要统计信息；表后只写必要结论，不再用长句重复报数。
复核不限字数回复是否把正文和补充材料的相关证据摘成表格并标明出处。
通用模板和完整示例使用明显的 mock 名称、结果和出处，如 Method A、Metric A、Metric B；不用具体研究内容和数值。Novelty 文风示范可保留作者明确提供的原句与数据。
检查 novelty 开头是否具体肯定了审稿人有依据的正确判断，并紧接核心贡献和证据表；不能用泛泛感谢替代。
```

## Revise loop

```text
运行 Revise loop，逐位处理审稿人。
论文：【】；每位审稿人的完整原话、原评分和后续讨论：【】；画像：【】；当前回复：【】；真实证据：【】；当轮评分、字数及使用规则：【】；允许修改的文件：【】。

1. 读取 rebuttal-reviewer-profile skill。分别扮演每位审稿人，依据其完整原话和画像设定关注点、严格程度与阅读习惯。
2. 按原问题清单逐题审核，检查是否简洁、直白地回答问题，删去空话、套话和防御性陈述；核对相关原文和实验数据是否摘入表格并标明出处。输出：Q｜对应原话｜回复位置｜是否回答｜具体意见｜缺失依据｜最小改法。
3. 给出本位审稿人的整体模拟判断：提分 / 维持 / 降分 / 无法判断，并说明原话依据与回复依据。仅在已提供真实原评分和当轮量表时给出模拟分数；始终标明“模拟”。
4. 若模拟提分，记录理由，结束该审稿人的循环，交作者人工确认。若模拟降分，先列明降分理由及对应 Q，再读取 rebuttal skill，按理由修改获授权的回复。维持时针对未解决的关切修改；若已无可执行修改或原分已满分，记录理由并交作者人工确认。缺材料而无法判断时交作者确认。
5. 修改后，用同一份原话、同一画像和同一评分口径重新审核，再判断提分、维持还是降分。不降低标准，不编造结果；缺数据或需要实验时单列待办。
6. 各位审稿人的模拟循环结束后，交作者逐题核对事实、数值、引用、实验状态和修改位置，确认没有幻觉。人工发现问题时修正并复核受影响的回复。

最终交付：可复制的正式回复；独立的内部模拟改分判断、理由与修改记录；实验或证据缺口；待人工确认事项。模拟判断不放入正式回复或 AC letter，不自动提交。
```
