# AC letter · 提示词

```text
请仅整理 AC letter。读取完整 reviews【】、评分【】、真实二轮记录【】、已完成的 rebuttal【】及当轮规定【】。每位审稿人单独一段：具体认可与评分 → 具体问题 → 直接回答和对应回复或证据表位置。只引用真实记录，有实际改分才写变化；省去泛泛致谢、重复总结和空泛收尾。详细原文和实验数据表留在逐题 rebuttal。审稿人及评分加粗，正面原话加粗斜体并保留引号。全文不超过 500 词或当轮更低上限。输出可复制的英文信，内部批注另放。
表达要求：用最简洁、最直白的话回答对方的具体问题，先给答案，再给必要证据和位置。不用空话、套话，不重复背景和结论，不作无关扩展。不添加任何防御性陈述。
实验数据优先用表格呈现，列出对照、关键条件、数值、单位及必要统计信息；表后只写必要结论，不再用长句重复报数。
通用模板和完整示例使用明显的 mock 名称、结果和出处，如 Method A、Metric A、Metric B；不用具体研究内容和数值。Novelty 文风示范可保留作者明确提供的原句与数据。
没有真实正面评价时省去认可句，直接写问题与回答。
```
