# AC letter · 规则与模板

方括号填写真实材料；模拟反馈供作者内部使用。

<a id="ac-letter"></a>
### AC letter 怎么写

AC letter 最后写。每位审稿人一段：具体认可与评分 → 具体问题 → 直接回答和证据位置。没有正面评价时，直接写问题与回答。

- 【铁律】用最简洁、最直白的话回答对方的具体问题，先给答案，再给必要证据和位置。不用空话、套话，不重复背景和结论，不作无关扩展。不添加任何防御性陈述。
- 有真实正面评价时，先写具体认可与评分；没有就直接写问题与回答。省去泛泛致谢。
- 有真实涨分、认可或问题解决的二轮回复，优先陈述改分前后与认可原话；没有就删去该项。没有回复只陈述客观状态，不能把沉默写成认可，也不能预期问题已经解决。
- 每位审稿人单独一段：具体认可与评分 → 具体问题 → 直接回答和关键证据位置。前句已说清时不再追加总结。
- 格式保持统一：审稿人及 Overall、Confidence 加粗；直接引用的正面原话用加粗斜体并保留引号；回应中只加粗一两个关键结果或结论。问题概括和解释用普通正文，不把整段全部加粗。
- AC 想知道关切是否被认真回应。概括最关键的数据、对照或修改，并给简短位置；不展开实验流程、方法细节、公式或整份逐题回复。
- 重点呈现论文的贡献、审稿人的认可和已经完成的回应。引用必须忠于原意；不把作者的解释写成审稿人的认可，不制造共识。确有剩余分歧时如实交代必要信息，不编造“全部解决”。
- 不要贬低或指挥审稿人和 AC。若有必要说明评审之间的分数差异，只用真实记录与可核对事实，让 AC 判断；不能仅凭 Confidence 或未回复就推断审稿人失职。
- 全文不超过 500 个英文单词；会议上限更低时遵守会议上限。不用破折号连接句子。
- 适用时补一句真实的代码开放或可复现状态；尚未完成的只能写真实承诺，不能冒充已发布。以具体回应自然结束，不另加空泛收尾。

#### 称呼与开头

称呼单独一行，随后直接写审稿人的具体认可和问题。省去泛泛致谢。

#### 可选：真实讨论更新

有实际改分或明确认可时，用一句话引用真实记录；没有就省略。

#### 每位审稿人第 1 句：先写肯定意见

用“Reviewer [ID] (Overall [current score], Confidence [confidence]) recognized [strength] as "[exact quotation]".”起句。审稿人及评分加粗；正面原话保留引号并用加粗斜体。评分字段按平台提供的真实记录填写，缺少字段时删去。

#### 第 2 句：写具体问题

写“The reviewer asked [specific question].”或直接概括该问题，删去宽泛的方面分类。

#### 第 3 句：直接回答并给出处

直接写答案与最关键的依据，给对应的 rebuttal 问题编号或证据表位置。

#### 答清即停

前面的回答与证据已说明问题，就结束该段。

#### 材料状态与结尾

如与评审有关，可在结尾前用一句话写真实的代码或数据开放状态；未完成的公开计划用承诺措辞。用具体回应自然结束，不另加空泛收尾。字数、证据核对和内部批注另放，不进入可复制的正式信。

### 7.2 AC letter 模板

```markdown
Dear [chairs],

[If recorded: Reviewer ID changed the Overall score from X to Y and wrote, “Exact discussion quote.”]

**Reviewer [ID] (Overall [score], Confidence [confidence])** described [specific contribution] as ***“[exact positive quotation]”***. The reviewer asked [specific question]. [Direct answer] ([rebuttal question or evidence-table location]).

**Reviewer [ID] (Overall [score], Confidence [confidence])** recognized ***“[exact positive quotation]”***. The reviewer asked [specific question]. [Direct answer] ([rebuttal question or evidence-table location]).

[If relevant: The code or data are available at permitted location.]
```

按实际人数增删；只保留真实的引用、评分、讨论更新和开放状态。详细原文和实验数据表放在逐题 rebuttal，AC letter 给关键答案及位置。 没有真实正面评价时省去该句，直接写问题和回答。
