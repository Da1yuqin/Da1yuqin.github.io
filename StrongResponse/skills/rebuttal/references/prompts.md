# Rebuttal · 提示词

```text
读取 rebuttal/SKILL.md。论文：【】；完整 reviews：【】；审稿人画像：【】；真实证据与位置：【】；当轮规则、字数和允许修改的文件：【】。先不限字数，按合作模板逐题写清拟回答、思路、依据、缺口与合作确认事项。汇总去重后的实验编号、对应 Q、目的、对照、判断依据和分工，分别报告必做新增、已完成、剩余、可选、待确认项及单列的重跑和重分析；运行次数另列。确认后起草完整或限字回复，首句先回答，再给必要依据、解释与位置，填入后按实际口径计数。模拟降分按理由修改，维持时处理未解决关切，再交同一角色复核；模拟提分后交作者人工核对事实与幻觉。AC letter 另用独立 skill。
```
