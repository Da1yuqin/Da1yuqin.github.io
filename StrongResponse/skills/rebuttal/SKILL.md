# Rebuttal

只负责逐题回复、追问与根据模拟意见修改。审稿人分析和模拟交给独立的 rebuttal-reviewer-profile，AC 信交给独立的 ac-letter。完整格式与模板见 [rules.md](references/rules.md)，复制提示词见 [prompts.md](references/prompts.md)。

## 表达要求

用最简洁、最直白的话回答对方的具体问题，先给答案，再给必要证据和位置。不用空话、套话，不重复背景和结论，不作无关扩展。不添加任何防御性陈述。

## 合作初稿与实验盘点

先不管字数，按“审稿意见 → 需补充的点 → 分版本逐题回复”整理合作稿。每题写清在问什么、拟直接回答、回复思路、已有依据、缺口、实验需求和合作确认事项。把实验统一编号并与各题双向关联，合并重复需求，分别统计必做新增、可选、待确认、已完成与剩余项；重跑、已有结果重分析、文字任务另列。实验项数和实际运行次数分别报告，未知写待定，不把同一实验的多次引用重复计数。

思路和证据确认后再写正式回复；按当轮限制选择完整 Q&A 或按审稿人分组的限字列表。限字前确认计数单位和限制范围，填入实际文本后核对计数。空白模板填写真实材料，完整示例展示写法。

## 证据表

实验数据优先用表格呈现，列出对照、关键条件、数值、单位及必要统计信息；表后只写必要结论，不再用长句重复报数。

不限字数的 rebuttal 中，正文和补充材料里能直接回答该题的原文、定义、设置和结果，必须全部摘进该题的证据表，并标明节号、表号或行号。按实际相关内容增行，不固定证据条数或来源类型。

原文逐字摘抄并加引号，节选标出省略；数据保留原数值、单位、条件、样本数、运行数及原报告的不确定性。转述明确写成转述。

## 示例规范

通用模板和完整示例使用明显的 mock 名称、结果和出处，如 Method A、Metric A、Metric B；不用具体研究内容和数值。Novelty 文风示范可保留作者明确提供的原句与数据。

## 输入与起草

读取论文、完整 review、已有结果与位置、当轮规定和作者授权范围。有画像时，将其核心关切、证据偏好和解释需求作为输入。

- 默认每位审稿人单独一份 Markdown；平台要求合并时按平台格式交付。按原 review 顺序提取 Weaknesses、Questions、建议与评分理由的具体问题，一句话有多问就拆开。
- 完整回复可用 `> **Q1.1: [忠于原意的问题标题]**`，也可按原审稿章节使用 `> #### **W1. [问题要点]**`：Weaknesses 用 W，Questions 用 Q，Strengths 用 S，Suggestions 用 SG；首次说明缩写，每章独立编号，保留原顺序。子问用 Q1.1a、Q1.1b 或 W1a、W1b。限字版可用问题编号与简短要点的列表，仍与合作稿逐题对应。
- 对 ICLR 这类当轮允许修改正文的会议，用有颜色的字体标注正文改动，在回复中说明改了什么及具体位置；非必要不大改，以解决审稿问题和 typo 为主，遵守当轮规定。
- 第一句通常直接回答。是否题给 Yes/No 或不能判断，原因题给理由，流程题给操作，数值题给具体值。
- 随后给必要设置、真实证据和解释。实验数据放进表格，只补回答该问题必需的解释，给表号、节号或行号。
- 可比较的数据用紧凑表格，保留数值、设置、单位与范围；结果不利时如实报告，说明实际差异，不编造借口。
- 根据画像调节回复：实验需求用对应数据，背景需求用概念和 case，讨论需求认真展开；感谢具体、克制，通常放在相关解释后或文末。回应 novelty／贡献质疑时，先准确肯定审稿人说对的具体点，学习“You correctly identify [specific mechanism] as [its supported role].”的文风。接着用一句话说核心贡献，再用表格给证据。用具体理解提供情绪价值，省去泛泛感谢和恭维。
- 每问一个清楚的回应，短句与短段落。承诺不是已完成结果；已有结果、阶段性证据与未来计划分别写清。

## 根据模拟反馈修改

接收 reviewer-profile skill 的 Q、画像关注点、回复位置、具体问题和最小改法；只修改不通过项。补回答、证据、实验分析、术语解释、表格或语气后，把新回复交回同一画像复核，按 Revise loop 的模拟改分判断继续：模拟降分先给具体理由，按理由改；维持则处理未解决关切；若已无可执行修改或原分已满分，记录理由交作者人工确认；模拟提分后结束该审稿人的循环，交作者人工核对回答完整性、事实和幻觉。

不重新编造审稿人人设，不用自己写的检查清单替代原问题。缺数据就说明缺口，补实验和改论文另由作者决定；只编辑获授权的回复文件，不编造结果、引用、真实改分或已经完成的修改。提交另按作者授权执行。
